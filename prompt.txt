project_name: SecurePrompt

Problem Statement :
With the rapid adoption of AI assistants like ChatGPT, Claude, and Gemini, employees and
common users often paste confidential information into public AI chatbots without realizing
the security implications.
This can unintentionally expose:
 Personally Identifiable Information (PII)
 Financial information
 Client and project details
 API keys and credentials
 Internal company documents
 Business strategies
Current solutions either block prompts completely or lack explainability, reducing productivity
and frustrating employees.

Proposed Solution :
We propose an AI-powered Browser Extension that acts as an intelligent security gateway
between employees and AI chatbots.
Before a prompt is sent, the extension automatically:
 Detects sensitive information using Microsoft Presidio, Regex, and custom enterprise
detection rules.
 Calculates an explainable risk score.
 Explains why each detected item is sensitive.
 Gives users complete control by allowing them to:
o Generate a privacy-safe version of the prompt
o Send the original prompt after understanding the associated risks
 Uses a self-hosted open-source LLM (llama 3.1 (exisitng local model in my device)) to rewrite prompts while preserving
the user's intent.
The solution follows the principle:
"Educate users instead of simply blocking them."
